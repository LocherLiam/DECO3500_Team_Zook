# DECO3500_Team_Zook
Welcome to the project wiki for Zook, a social and mobile computing design project developed by Team 28 for DECO3500.

Zook explores how physical interaction and digital technology can work together to support more engaging, inclusive and continuous collaboration between university students. Our project focuses on students completing group assessments in UQ classrooms, where collaboration often moves between face-to-face discussion, physical materials and separate digital tools.

GitHub: https://github.com/LocherLiam/DECO3500_Team_Zook.git

File structure is self explanatory in the repository, find all documentation of design activities in "documentation" and assessment pieces have their own dedicated folder.
